v0.2.4 — Mac 설치·업데이트 복구

2026-11-07GitHub Release

Mac 설치 뒤 DMG를 다시 설치하라는 안내와 업데이트 반복을 수정했습니다.

  • macOS 기본 복사 과정에서 필수 검증 파일이 누락되지 않도록 초기 설치 manifest 위치를 수정했습니다.
  • 앱 교체 실패 시 이전 버전을 보존하고 같은 업데이트를 자동 반복하지 않습니다.
  • 읽기 전용 디스크와 설치 폴더 쓰기 권한 문제를 구분해 안내합니다.
  • ARM·Intel의 실제 DMG 복사·첫 실행·권한 실패 복원·재실행 검사를 추가했습니다.

0.2.3 앱 자체가 실행되지 않으면 새 DMG의 앱을 응용 프로그램 또는 ~/Applications에 한 번 새로 복사하세요. 게임과 설정을 삭제할 필요는 없습니다. 실행 가능한 기존 런처는 업데이트 시작 버튼을 사용하세요.

macOS15 이상을 지원합니다. Windows Authenticode와 Apple Developer ID·공증은 아직 제공하지 않습니다. 보안 기능을 끄거나 백신 예외를 추가하지 마세요. 사람의 Mac 이메일 인증·게임 플레이·재부팅은 별도 검증 범위입니다.

v0.2.3 — 기기 로그인 유지와 사용성 개선

2026-11-05GitHub Release

이메일 인증 후 기기 로그인을 유지하고, 평소 버전 확인 표시를 간소화했습니다.

  • 최초 이메일 인증 후 암호화된 기기 키로 로그인을 유지합니다. 로그아웃·운영자 회수·키 손상/분실·180일 미사용 시 다시 인증합니다. 기존 사용자는 기기 등록 안내를 확인하고 동의한 뒤 진행합니다.
  • 인증과 서버 확인을 마치면 런처 창으로 돌아옵니다. OS가 포커스를 허용하지 않으면 작업표시줄 또는 Dock의 런처를 선택하세요.
  • 파일 메뉴에 런처 설치 폴더 열기를 추가했습니다. 도움말의 런처 정보에서도 설치 경로를 확인할 수 있습니다.
  • 주기·화면 복귀 시 버전 확인은 우측 하단의 버전 확인중과 점으로 표시합니다. 실제 업데이트는 별도 승인·진행 창을 유지합니다.
  • 기기 요청의 일회용 서명, 접근 회수와 손상 처리, Windows 실행 파일 보호를 보완했습니다.

Windows는Setup, Apple Silicon/Intel Mac은각 아키텍처DMG로 설치합니다. 게임·설정은 같은 사용자 프로필에 보존되며 앱 제거와 로그아웃은 별개입니다. 게임 업데이트는 업데이트 버튼으로 적용하고, 플레이에는 서버 연결이 필요합니다.

Windows 게시자 서명과 Apple Developer ID·공증은 아직 없습니다. 첫 실행 안내는 다운로드 페이지 FAQ를 확인하세요. 운영체제의 보안 기능을 끄지 마세요.

v0.2.2 — 업데이트 승인·연결 확인·설치 오류 수정

2026-11-05GitHub Release

이메일 인증 전에 업데이트를 알리고 승인 후 설치하도록 바꿨습니다.

  • 새 버전이 있으면 현재·새 버전과 업데이트 시작 버튼을 먼저 표시합니다. 승인 후 별도 진행 모달에서 다운로드·검증을 진행하고 설치가 끝나면 자동으로 다시 실행합니다.
  • 시작 시, 실행 중 약1분 간격, 창으로 돌아왔을 때 최신 버전을 확인합니다. 사이트와 GitHub의 서명 피드를 비교해 더 높은 배포 순서를 선택합니다. 확인 실패는 재시도 안내를 표시하며 조용히 넘어가지 않습니다.
  • 인터넷 연결·최신 런처 확인·이메일 인증을 마치기 전에는 게임 실행을 포함한 런처 기능을 사용할 수 없습니다. 오프라인 플레이 우회를 제거했고 게임 실행 직전에도 실제 연결·서명된 배포 정보를 확인합니다.
  • 실제0.2.0→0.2.1 자동 설치에서 발생한 ‘업데이트 요청자를 확인하지 못했습니다’ 오류를 수정했습니다. 종료된 프로세스 핸들이 남는 조건을 별도 재현하고, OS 생성 시각·bootstrap 기록·활성 슬롯·전체 파일을 확인하도록 했습니다. 다른 실행 중인 프로세스는 허용하지 않습니다.
  • 설치기의 한글 오류 출력 인코딩을 보완했습니다. 구형 Windows 런처가 업데이트를 넘겨도 새 설치기에서 적용 전 업데이트 승인을 표시합니다.
  • 게임 업데이트는 별도 업데이트 버튼으로 직접 적용합니다. 제거·재설치 시 게임·설정·저장 데이터는 보존합니다. 이메일 인증은 계속 누구나 가능하며 별도 유료 서비스를 추가하지 않았습니다.

0.2.0/0.2.1은 이번 패치로 전환해야 새 승인 흐름을 사용할 수 있습니다. 기존 Windows ZIP 사용자는 최신 Setup으로 한 번 설치하세요. Mac(macOS15 이상)은 CPU에 맞는 DMG를 받으세요.

Windows 게시자 서명과 Apple Developer ID·공증은 아직 없습니다. 공식 다운로드 및 첫 실행 안내: https://testlauncher.teamhjd.com/

v0.1.4 — 공통 아이콘·업데이트·인증 안내

2026-11-03GitHub Release

공통 로켓·재생 배지 아이콘을 Windows 실행 파일·실행 중 창·macOS 앱에 적용했습니다.

기존 설치에서도 실행할 때마다 이메일 인증보다 먼저 런처 업데이트를 확인합니다. 업데이트 확인·다운로드·검증·적용 대기와 이메일 인증은 별도 모달로 표시하고 다른 조작을 막습니다. 설치된 클라이언트를 직접 실행해도 정상 설치 경로와 실행 파일 receipt가 확인되면 자동 업데이트 경로를 복원합니다.

이메일 인증이 만료된 상태를 ‘자동 재연결 중’으로 잘못 표시하던 문제를 수정했습니다. 이제 ‘이메일 재인증 필요’와 바로 누를 수 있는 인증 버튼을 표시하며, 서버 연결 실패는 ‘서버 오프라인’, 인증과 게임 목록 검증 성공은 ‘서버 온라인’으로 구분합니다. 이메일 인증이 만료되거나 업데이트 확인에 실패해도 설치된 게임은 모달의 오프라인 플레이로 계속 사용할 수 있습니다. 게임 파일 검증과 명시적 게임 업데이트는 유지합니다.

런처 자체 업데이트는 게임 서버의 이메일 인증과 별개로 GitHub에서 확인합니다. 새 payload를 검증한 뒤 다음 실행에 적용합니다. 기존 portable의 고정 실행 파일·Finder 앱 아이콘까지 바꾸려면 새 portable ZIP으로 교체해야 합니다. 게임과 설정을 삭제할 필요는 없습니다.

Windows x64, macOS Apple Silicon, macOS Intel ZIP을 제공합니다. macOS 최소 버전은12입니다. Windows 게시자 서명과 Apple Developer ID/공증은 없습니다. 인증·다운로드·게임 플레이의 보안 검증을 끄지 마세요.

공개 파일은 런처·의존성·라이선스만 포함하며 게임·개인정보·접근 자격 증명은 포함하지 않습니다.

v0.1.3 — Windows + macOS

2026-10-30GitHub Release

Windows와 macOS에서 같은 이메일 인증 채널로 게임을 받는 런처입니다.

  • Apple Silicon: TeamHJD-GameTestLauncher-macOS-arm64.zip
  • Intel Mac: TeamHJD-GameTestLauncher-macOS-x64.zip
  • Windows: TeamHJD-GameTestLauncher-Windows-x64.zip

맥은 macOS 12 이상에서 ZIP을 풀고 TeamHJDLauncher.app을 응용 프로그램 폴더로 옮겨 실행하세요. 인증 정보는 macOS 키체인으로 보호합니다. Windows는 폴더 전체를 풀어 TeamHJDLauncher.exe를 실행하세요.

이메일로 시작 → 브라우저에서 이메일·일회용 코드 인증 → 설치 → 플레이 순서로 사용합니다. 게임은 운영체제와 CPU에 맞는 서명된 패키지를 자동 선택합니다. 새 게임 버전은 자동으로 알려 주며, 업데이트를 눌러 적용하거나 현재 버전 플레이를 선택할 수 있습니다. 런처 자체 업데이트는 다음 실행에 적용합니다.

게임은 런처에서 이메일 인증 후 설치하세요. 기존 수동 게임 ZIP 웹페이지는 종료했습니다. Windows와 맥의 현재 테스트 게임은 BUILD0024 / HFH-FIELD-v14입니다. 기존 Windows 0.1.2에서도 배포 목록 호환성을 확인했습니다.

macOS 배포에는 Apple Developer ID와 공증이 없습니다. 실행이 차단되면 공식 파일을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 그래도 열기를 선택하세요. 처음 인증하거나 런처가 바뀐 뒤 키체인 접근 허용을 요청할 수 있습니다.

공개 ZIP에는 런처와 필요한 라이브러리·라이선스만 포함됩니다. 게임·음악·접속자 기록·인증 정보는 포함하지 않습니다. 게임은 별도의 인증 서버에서 배포합니다. 맥 게임의 실제 화면·소리·입력과 Windows↔Mac 네트워크 플레이는 실기기 플레이테스트가 필요합니다.

  • TeamHJD 원본 로고를 창·실행 파일 아이콘에 적용
  • 일체형 상단 바, 파일·보기·도움말 메뉴, 알림함과 토스트
  • 서버·버전 자동 확인, 게임 자동 업데이트, 런처 다음 실행 자동 업데이트
  • 같은 패키지 중복 설치 방지, 다운로드 이어받기, 파일 검증·복구·이전 버전 복원
  • 설치/최신/이전 버전과 변경사항·용량 확인, 게임 삭제·재설치
  • 실행 중 설치/삭제 차단, AppData 저장 데이터와 외부 테스트 로그 보존

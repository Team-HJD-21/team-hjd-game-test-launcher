첫 실행 FAQ

현재 테스트 배포본은 Windows 게시자 서명과 Apple Developer ID 서명·공증이 없어, 처음 실행할 때 보안 경고가 나타날 수 있습니다.

이 페이지에서 연결한 공식 GitHub 파일을 받았고 출처를 신뢰하는 경우에만 아래 절차를 진행하세요.

Windows‘Windows의 PC 보호’가 표시되나요?
  1. 공식 Setup.exe를 실행하세요. 관리자 권한 없이 현재 Windows 계정에 설치합니다.
  2. SmartScreen 경고 창에서 ‘추가 정보’를 누르세요.
  3. 앱 이름이 TeamHJD-GameTestLauncher-Windows-x64-Setup.exe인지 확인하고 ‘실행’을 선택하세요.

게시자가 ‘알 수 없는 게시자’로 표시될 수 있습니다. ‘실행’ 버튼이 없거나 Smart App Control·조직 정책으로 차단되면 아래 공통 안내를 확인하세요.

Microsoft 안내 ↗
macOS개발자를 확인할 수 없어 열리지 않나요?
  1. DMG를 열고 TeamHJDLauncher.app을 응용 프로그램 폴더로 옮긴 뒤 한 번 실행하세요. 개발자 확인·Apple 검사 관련 경고가 뜨면 닫으세요.
  2. ‘시스템 설정 → 개인정보 보호 및 보안’을 여세요.
  3. TeamHJDLauncher의 차단 안내 옆 ‘그래도 열기’를 누르고, 확인 창에서 ‘열기’를 선택하세요. Mac에서 인증을 요청하면 해당 시스템 창에서 승인하세요.

‘그래도 열기’가 보이지 않으면 앱을 다시 한 번 실행한 직후 설정을 확인하세요. OS 버전에 따라 문구와 버튼 위치가 다를 수 있습니다.

Apple 안내 ↗
공통계속 차단되거나 ‘손상됨’ 경고가 뜨나요?

‘악성코드’, ‘컴퓨터를 손상시킴’, ‘앱이 손상됨’ 경고는 단순한 개발자 확인 경고와 다릅니다. 실행을 중단하고 이 페이지에서 새로 받은 파일로도 같은 경고가 뜨는지 확인한 뒤 문의해 주세요.

실행 버튼이 없거나 회사·학교 PC의 정책으로 차단되면 담당 관리자에게 문의하세요. 백신·SmartScreen·Gatekeeper 전체를 끄는 방식은 사용하지 마세요.

경고 화면과 OS 버전을 첨부해 문의하기 ↗
공통기존 ZIP 사용자 전환·자동 업데이트·제거는?

기존 사용자는 런처를 종료하고 새 Setup을 한 번 설치하거나, Mac의 새 앱을 응용 프로그램 폴더로 옮기세요. 같은 사용자 계정의 게임과 설정을 이어서 사용합니다. 예전 작업표시줄 고정을 해제하고 설치된 TeamHJDLauncher를 다시 고정하세요.

런처가 이메일 인증 전에 새 버전을 확인합니다. 업데이트 시작을 누르면 다운로드·검증·설치 후 자동으로 다시 실행됩니다. 인터넷 연결과 최신 버전 확인을 마치기 전에는 게임 실행을 포함한 기능을 사용할 수 없습니다. 게임 업데이트는 별도 업데이트 버튼으로 적용합니다.

Windows는 설정 → 앱 → 설치된 앱에서 제거합니다. Mac은 응용 프로그램의 TeamHJDLauncher.app을 휴지통으로 옮깁니다. 게임·설정·로그인 정보·Unity 저장 데이터와 서버 기록은 보존됩니다. 로그인 정보는 런처 파일 메뉴에서, 게임은 게임 관리에서 별도로 삭제할 수 있습니다.

파일이 손상되면 최신 Setup을 다시 실행하거나 새 DMG의 앱으로 교체하세요. 프로그램 제거 후 재설치도 가능합니다. 서버 기록의 삭제·동의 철회는 support@teamhjd.com으로 요청하세요.

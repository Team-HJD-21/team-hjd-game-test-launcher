# TeamHJD Game Test Launcher

ZIP을 일반 폴더에 풀고 `TeamHJDLauncher.exe`를 실행하세요. 관리자 권한은 필요하지 않습니다. 업데이트를 저장할 수 있도록 쓰기 가능한 위치를 사용하세요.

1. **이메일로 시작**을 누른 뒤 안내를 확인하고 **브라우저에서 인증**을 선택하세요.
2. 브라우저에 이메일을 입력하고 메일로 받은 일회용 코드를 입력하세요. 인증이 끝나면 런처로 돌아오세요.
3. **설치**를 누르세요. 다운로드와 파일 검증이 끝나면 **플레이**로 시작하세요.

팀에서 별도 `.hjdinvite` 초대 파일을 전달한 경우에는 파일을 런처에 끌어 놓거나 설정의 고급 연결 설정에서 가져올 수 있습니다.

연결과 최신 버전은 시작할 때, 창으로 돌아올 때, 실행 중 약 2~2.5분마다 자동 확인합니다. 게임의 새 버전이 있으면 현재 버전과 최신 버전이 함께 표시됩니다. **업데이트**를 눌러야 다운로드와 설치가 시작됩니다. 게임을 종료하거나 런처를 다시 열어도 게임 업데이트가 자동으로 시작되지 않습니다.

바로 업데이트하지 않으려면 **현재 버전 플레이**를 누르세요. 같은 패키지는 중복 설치하지 않습니다. 게임 실행 중에는 업데이트할 수 없으며, 종료한 뒤 **업데이트**를 눌러 적용하세요. 취소한 다운로드는 다시 업데이트하거나 설치할 때 이어받습니다. 네트워크가 끊겨도 설치된 게임은 실행할 수 있습니다.

게임 관리 `···`에서 버전·변경사항·사용 용량, 설치 폴더, 테스트 로그, 파일 복구, 이전 버전 복원과 게임 삭제를 사용할 수 있습니다. 게임 삭제는 설치 파일과 보관 버전을 지우고, AppData 저장 데이터와 외부 테스트 로그는 보존합니다. 실행 중에는 삭제할 수 없습니다. 로그는 자동 전송하지 않습니다. 파일 복구는 서버 연결이 필요합니다. 이전 버전 복원은 로컬 파일을 검사한 뒤 진행합니다. 복원한 버전으로 계속 플레이하거나 **업데이트**를 눌러 최신 배포를 다시 적용할 수 있습니다.

런처의 새 버전도 자동으로 내려받아 다음 실행 때 적용합니다. 새 런처가 정상 화면을 띄우지 못하면 이전 버전으로 자동 복원합니다. 게임 저장 데이터는 게임이 관리하는 AppData/LocalLow 경로에 그대로 남습니다.

상단의 파일·보기·도움말 메뉴와 알림함을 사용할 수 있습니다. `Ctrl+,`는 설정, `Ctrl+B`는 사이드바, `F1`은 도움말입니다. 창 이동은 상단 빈 영역을 끌고, 창 크기는 가장자리를 끌어 조절하세요.

이메일 인증은 Cloudflare Access에서 처리합니다. TeamHJD는 인증된 이메일, 최초·최근 인증 시각, 최근 접속 시각과 인증 횟수를 비공개 운영 서버에 보관합니다. 연결 토큰은 이 PC의 Windows 계정으로 암호화해 저장합니다. 이메일 인증이 만료되면 파일 메뉴나 설정에서 다시 인증하세요. 게임 내 멀티플레이 방 암호는 이메일 인증과 별개입니다.

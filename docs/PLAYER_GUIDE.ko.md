# TeamHJD Game Test Launcher

ZIP을 일반 폴더에 풀고 `TeamHJDLauncher.exe`를 실행하세요. 관리자 권한은 필요하지 않습니다. 업데이트를 저장할 수 있도록 쓰기 가능한 위치를 사용하세요.

1. **테스트 서버 연결**을 누르세요.
2. 팀에서 전달한 `invite.json`을 가져오고, 별도로 받은 접근 암호를 입력하세요.
3. **저장하고 연결**을 누른 뒤 게임의 **설치**를 선택하세요.
4. 설치가 끝나면 **플레이**로 시작하세요.

연결과 최신 버전은 자동 확인합니다. 설치한 게임의 새 버전은 선택했을 때 자동으로 준비하며, 실행 중이면 게임을 종료할 때까지 기다립니다. 같은 패키지는 중복 설치하지 않습니다. 취소한 다운로드는 다시 설치할 때 이어받습니다. 네트워크가 끊겨도 설치된 게임은 실행할 수 있습니다.

게임 관리 `···`에서 버전·변경사항·사용 용량, 설치 폴더, 테스트 로그, 파일 복구, 이전 버전 복원과 게임 삭제를 사용할 수 있습니다. 게임 삭제는 설치 파일과 보관 버전을 지우고, AppData 저장 데이터와 외부 테스트 로그는 보존합니다. 실행 중에는 삭제할 수 없습니다. 로그는 자동 전송하지 않습니다. 파일 복구는 서버 연결이 필요합니다. 이전 버전 복원은 로컬 파일을 검사한 뒤 진행하며, 같은 배포를 자동으로 다시 적용하지 않습니다.

런처의 새 버전도 자동으로 내려받아 다음 실행 때 적용합니다. 새 런처가 정상 화면을 띄우지 못하면 이전 버전으로 자동 복원합니다. 게임 저장 데이터는 게임이 관리하는 AppData/LocalLow 경로에 그대로 남습니다.

상단의 파일·보기·도움말 메뉴와 알림함을 사용할 수 있습니다. `Ctrl+,`는 설정, `Ctrl+B`는 사이드바, `F1`은 도움말입니다. 창 이동은 상단 빈 영역을 끌고, 창 크기는 가장자리를 끌어 조절하세요.

접근 암호와 게임 내 방 암호는 서로 다릅니다. 초대 파일의 주소·배포자 키는 팀이 전달한 값인지 확인하세요. 서버가 아직 배포되지 않았다면 팀의 서버 설정이 끝난 뒤 연결할 수 있습니다.

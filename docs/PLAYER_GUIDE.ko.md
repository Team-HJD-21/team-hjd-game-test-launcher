# TeamHJD Game Test Launcher 사용 안내

[TeamHJD 홈페이지](https://teamhjd.com/) 푸터 **관련 사이트 → Game Test Launcher**에서 [다운로드 페이지](https://testlauncher.teamhjd.com/)를 엽니다. Windows 10/11 x64는 **Setup.exe**를 실행합니다. 현재 Windows 계정에 설치하며 관리자 권한은 필요하지 않습니다. 시작 메뉴의 **TeamHJD Game Test Launcher**를 실행하고 이 바로가기를 작업표시줄에 고정하세요.

## 기존 ZIP 사용자의 이번 한 번 전환

기존 런처를 종료한 뒤 Setup을 설치하세요. 같은 Windows 계정의 게임·설정·로그인 정보는 기존 위치를 이어서 사용합니다. 이전 ZIP의 파일을 새 설치 폴더에 덮어쓰지 마세요. 예전 작업표시줄 고정을 해제하고 시작 메뉴의 새 런처를 고정하세요. 새 설치를 확인할 때까지 기존 ZIP을 보관해도 됩니다. 기존 ZIP의 업데이트 확인이 GitHub 제한에 걸린 경우에도 새 Setup으로 바로 전환할 수 있습니다.

## 처음 참여하기

1. 시작 시 런처 업데이트를 먼저 확인합니다. 새 버전은 업데이트 시작 버튼으로 승인한 뒤 다운로드·서명·전체 파일 검증·설치를 거쳐 자동으로 다시 시작합니다.
2. 온라인 참여 안내에서 개인정보 수집·이용과 Cloudflare 국외 처리를 각각 확인·선택합니다. 기본 선택은 해제되어 있습니다. 만14세 미만은 자동 인증 대신 담당자에게 법정대리인 동의 절차를 문의하세요.
3. **브라우저에서 인증**을 누르고 이메일과 메일로 받은 일회용 코드를 입력합니다. 완료 후 런처로 돌아옵니다.
4. **설치 → 플레이**로 게임을 시작합니다. 게임의 새 버전은 알림을 확인한 뒤 **업데이트**를 직접 눌러 적용합니다.

게임은 자동으로 새 버전을 설치하지 않습니다. **현재 버전 플레이**로 기존 버전을 계속 사용할 수 있습니다. 같은 검증된 패키지는 중복 설치하지 않습니다. 취소·통신 단절 후 다시 시도하면 다운로드를 이어받습니다. 게임 실행 중 설치·복원·삭제는 차단합니다.

## 업데이트·연결·인증

런처는 시작 시 및 실행 중 약15분마다 서명된 정적 배포 정보를 확인합니다. 오류는15초부터 최대약5분 간격으로 자동 재시도하며 최신 버전으로 오인해 온라인 기능을 열지 않습니다. 정상 실행 확인에 실패하면 이전 버전으로 복원하고 같은 실패 버전의 반복 재시작을 막습니다. **다시 설치 시도**는 복구 후 명시적으로 선택할 수 있습니다.

인터넷 연결·최신 런처 확인·이메일 인증을 마쳐야 게임을 실행할 수 있습니다. 오프라인 우회는 제공하지 않습니다. 연결 오류는 자동으로 재확인하며 업데이트 승인은 이메일 인증보다 먼저 표시합니다.

## 관리·복구·제거

게임 관리에서 버전·폴더·로그·파일 복구·이전 버전 복원·게임 삭제를 사용할 수 있습니다. 게임 삭제는 설치/보관 버전을 제거하며 Unity 저장 데이터와 테스트 로그는 유지합니다.

런처 파일이 손상되면 종료 후 공식 최신 Setup을 다시 실행하세요. Windows **설정 → 앱 → 설치된 앱 → TeamHJD Game Test Launcher → 제거** 또는 시작 메뉴의 제거 바로가기로 프로그램을 지울 수 있습니다. 실행 중에는 제거가 차단됩니다. 제거 후 재설치도 지원합니다.

프로그램 제거는 게임·설정·로그인 정보·Unity 저장 데이터·로그 및 서버 인증 기록을 보존합니다. 로그인 정보만 지우려면 런처 **파일 → 이 PC의 로그인 정보 삭제**를 사용하세요. 서버 기록의 열람·삭제·동의 철회·처리정지는 **support@teamhjd.com**으로 직접 요청할 수 있습니다. 앱 삭제와 서버 기록 삭제는 별개입니다.

기본 프로그램 위치는 `%LOCALAPPDATA%/Programs/TeamHJD Game Test Launcher/`, 설정·게임 기본 위치는 `%LOCALAPPDATA%/TeamHJD/Launcher/`입니다. 설정에서 고른 별도 게임 경로도 유지합니다. 폴더를 수동으로 일괄 삭제하지 마세요.

공식 파일에는 현재 Windows 게시자 서명이 없습니다. 출처와 파일명을 확인한 뒤 SmartScreen의 **추가 정보 → 실행**을 선택할 수 있습니다. 조직 정책·Smart App Control 등으로 실행 선택이 없으면 관리자에게 문의하세요. 보안 기능 전체를 끄지 마세요. [전체 FAQ·이용조건·개인정보 안내](https://testlauncher.teamhjd.com/privacy.html)를 확인할 수 있습니다.

배포 서버는 운영 PC의 Windows 사용자 로그인·절전 해제·인터넷 연결이 필요합니다. 이 서버와 게임 안에서 여는 멀티플레이 호스트는 별개이며 PC가 켜진 것만으로 게임 방이 자동 생성되지는 않습니다.

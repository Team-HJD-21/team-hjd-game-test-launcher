# 설치형·필수 업데이트 전환 계획

2026-11-05. 목표 릴리즈0.2.0. 추가 유료 저장소를 도입하지 않는다.

## 완료 기준

- Windows 사용자 단위 설치/복구/제거와 macOS DMG를 제공한다. 관리자 실행·운영체제 보호 해제를 기본 해결책으로 사용하지 않는다.
- 기존 게임/설정/인증 저장 위치를 이어받고, 앱 제거는 기본적으로 이 데이터를 보존한다. 외부 게임 경로와 Unity 저장 데이터를 앱 제거에 섞지 않는다.
- 정적 HTTPS 피드의 P-256 서명·시각·순서·플랫폼·정확한 파일 URL/크기/해시를 검증한다. 공개 GitHub REST API는 클라이언트/다운로드 페이지의 버전 확인에서 제거한다.
- 시작 시 업데이트 검증 전 온라인 기능을 열지 않는다. 다운로드/검증/자동 재시작/health ACK/실패 복원을 수행한다. 오류는 최신으로 표시하지 않고 재시도·오프라인 선택을 제공한다.
- 안정된 실행기와 실제 Client를 함께 관리한다. 이미 설치된 구형 실행기와의 전환 경로를 시험한다. 게임 업데이트는 명시적 버튼 적용을 유지한다.
- 피드는 모든 대상 릴리즈 파일이 공개·대조된 뒤 마지막에 게시한다. 기존 공개 태그/파일은 덮어쓰지 않는다. 피드 서명 개인키는 로컬 DPAPI 보관하고 공개 CI에 보내지 않는다.
- 설치/실행/웹의 약관·개인정보/라이선스 및 삭제 안내를 실제 동작과 맞춘다. 법적 적합성 인증을 주장하지 않는다.
- Windows 설치→기존 데이터 유지→업데이트→실패 복원→제거→재설치를 격리 환경에서 확인한다. ARM/Intel의 실제 native/delivery/DMG 검사를 별도로 통과한다.
- 공개 후 기존0.1.4 다운로드·검증·queue와 새 피드 기반 자동 전환을 검증하고 결과/한계를 새 검증 문서에 남긴다.

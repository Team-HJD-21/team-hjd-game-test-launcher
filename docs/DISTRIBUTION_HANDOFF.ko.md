# 설치형 배포·운영 안내

현재 정식 버전은 **0.2.0**입니다. [공식 다운로드](https://testlauncher.teamhjd.com/)에서 Windows Setup 또는 Mac DMG를 받습니다. Mac은 macOS 15 이상이며 Apple Silicon/Intel을 구분합니다.

## 팀원에게 보낼 문구

> 런처 0.2.0 설치형을 배포했습니다: https://testlauncher.teamhjd.com/
> 기존 ZIP 사용자는 런처를 닫고 이번에 한 번 Setup/DMG를 설치한 뒤 새 실행기를 작업표시줄/Dock에 고정해 주세요. 같은 계정의 기존 게임·설정은 이어서 사용합니다. 이후 런처는 자동 업데이트되고, 게임은 업데이트 버튼으로 적용합니다. 첫 실행 경고의 해결 방법은 페이지 FAQ에 있습니다.

팀원에게 자동 발송하지 않았습니다. 위 문구를 복사해 전달하면 됩니다.

## 사용하는 순서

1. Windows는 Setup을 실행합니다. Mac은 DMG를 열어 `TeamHJDLauncher.app`을 응용 프로그램 폴더로 옮깁니다. 버전 폴더의 Client를 직접 고정하지 않습니다.
2. 실행하면 이메일 인증에 앞서 서명된 최신 런처 정보를 확인합니다. 업데이트가 있으면 내려받기·검증·재시작을 진행합니다. 오류를 최신 상태로 표시하지 않으며 재시도합니다.
3. 온라인 참여를 원하면 개인정보 수집·이용, Cloudflare 국외 처리와 연령 확인을 각각 선택하고 브라우저의 이메일 일회용 코드로 인증합니다. 사용자 대신 선택하지 않습니다.
4. 게임을 한 번 설치한 뒤 플레이합니다. 새 게임 버전은 자동으로 확인·알림을 받고 **업데이트** 버튼으로 적용합니다. 이미 설치한 게임은 오프라인 선택 후 플레이할 수 있습니다.

Windows 앱 제거는 **설정 → 앱 → 설치된 앱**, Mac은 응용 프로그램의 앱을 휴지통으로 옮깁니다. 게임·설정·로그인 저장소·Unity 저장 데이터와 서버의 인증 기록은 보존됩니다. 로그인 정보는 런처의 해당 삭제 메뉴로, 서버 기록은 아래 권리 처리 절차로 따로 관리합니다. 최신 Setup/DMG로 복구·재설치할 수 있습니다.

## 서버와 인증 목록

바탕화면의 **TeamHJD Game Tester 관리** 또는 프로젝트의 다음 도구로 관리 화면을 엽니다.

```powershell
./tools/Open-HostingDashboard.ps1 -PrivateRoot .local/production-distribution
```

- **서버 관리**에서 시작·중지·다시 시작과 로그인 자동 시작을 관리합니다. 기본은 같은 Windows 사용자로 로그인한 뒤 시작하며, PC 종료 시 서비스도 종료됩니다. PC의 전원만 켜진 로그인 전 상태, 절전·인터넷 단절 중에는 제공되지 않습니다.
- 로그인 자동 시작 등록은 복구·확인했습니다. 이 PC의 안정된 PowerShell은 비공개 `production-distribution/tools/pwsh-7.6.5`에 있습니다. 실제 재부팅·로그온 시험은 아직 하지 않았습니다.
- **테스터 목록**에서 인증 이메일·최초/최근 인증·최근 요청 시각·관측 세션과 통계를 봅니다. 최근5분 요청 수는 실제 동시 접속자나 게임 실행자 수가 아닙니다. CSV/생성 HTML에는 개인정보가 있으므로 외부 공유하지 않습니다.
- 원본은 비공개 운영 폴더의 `verified-users.json`입니다. 마지막 접근 후180일이 지난 기록을 시작 시와 운영 중 매시간 정리합니다. PC가 꺼져 있으면 다음 시작에 처리합니다.
- 삭제·처리정지 요청은 **support@teamhjd.com**으로 받습니다. 정확한 한 명 삭제는 `Maintain-VerifiedUsers.ps1 -RemoveUser`로 미리보고 `-Apply`로 적용합니다. 이메일을 명령행에 넣지 않습니다. CSV·백업에도 적용하고, 재인증 시 새 기록 생성과 Access 세션 철회는 구분합니다.

게임 API는 기존 Cloudflare Access/Tunnel → `127.0.0.1:8443`입니다. 로컬 관리 서비스 `127.0.0.1:8844`를 외부에 노출하지 않습니다. 종료한 `/downloads` 포털을 복구하거나 `playtest` 도메인을 삭제하지 않습니다. 자세한 제어·권리 처리 절차는 [운영 가이드](PLAYTEST_HOSTING.ko.md)에 있습니다.

## 다음 릴리즈

[릴리즈 절차](RELEASING.ko.md)를 따릅니다. 검증된 Windows Setup·양쪽 Mac DMG/ZIP을 GitHub Draft에 올리고 실제11개 크기·digest를 대조한 뒤 공개합니다. **모든 파일이 공개된 다음** 로컬 키로 서명한 피드를 사이트에 게시합니다. 새 피드가 배포되면 웹사이트도 최신 버전과 설치 링크를 자동 표시합니다. 추가 유료 저장소는 사용하지 않습니다.

피드는 P-256 서명·단조 sequence·365일 유효기간을 사용합니다. 새 버전이 없어도 만료 전에 상위 sequence로 갱신해야 합니다. 개인키는 현재 Windows 계정의 DPAPI로 보호하며 Git/공개 CI에 넣지 않습니다. 암호화 파일만 다른 PC로 복사해 복구할 수 있다고 가정하지 않습니다. 이미 공개한 태그와 자산은 덮어쓰지 않습니다.

[0.2.0 검증 기록](RELEASE_VALIDATION_0.2.0.md)에는 실제 검사와 미검증 범위를 구분했습니다. Windows 게시자 서명·Apple Developer ID/공증은 아직 없으므로 첫 실행 경고가 있을 수 있습니다. 운영체제 차단·디스크 부족·인터넷 장애까지 강제로 해결하는 의미의 업데이트 보장은 하지 않습니다.

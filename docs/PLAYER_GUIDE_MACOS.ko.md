# 맥에서 플레이테스트 시작하기

게임을 바로 받아 수동 설치하려면 [이메일 인증 다운로드 페이지](https://playtest.teamhjd.com/downloads)에서 **macOS · Apple Silicon / Intel 다운로드**를 선택하세요. ZIP을 완전히 풀어 `HoseForHire.app`을 실행합니다. 런처에서 설치·업데이트를 관리하려면 아래 순서로 시작하세요. 수동 설치한 게임은 런처가 설치한 게임으로 자동 등록되지 않습니다.

macOS 12 이상에서 사용할 수 있습니다. Apple 메뉴 → 이 Mac에 관하여에서 칩을 확인해 Apple Silicon(M1 이상)은 `macOS-arm64.zip`, Intel은 `macOS-x64.zip` 런처를 받으세요. 게임은 같은 테스트 버전·통신 규약의 플랫폼별 패키지를 자동 선택합니다. Windows 실행 파일을 맥에 설치하지 않습니다.

1. 공식 GitHub Releases에서 ZIP을 받아 압축을 풉니다.
2. **TeamHJDLauncher.app**을 응용 프로그램 폴더로 옮기고 실행합니다. Dock에도 이 앱을 고정하세요.
3. **이메일로 시작**을 누르고 브라우저에서 이메일과 수신 코드를 입력합니다. 인증 후 런처로 돌아옵니다.
4. **설치**를 누르면 맥 게임 패키지를 내려받아 서명·해시·전체 파일을 확인합니다. **플레이**로 시작합니다.
5. 새 게임 버전은 자동으로 알려 줍니다. **업데이트**를 눌러 적용하거나 **현재 버전 플레이**로 기존 버전을 계속 사용하세요. 런처 자체 업데이트는 다음 실행에 자동 적용됩니다.

이 배포에는 Apple Developer ID 인증서와 Apple 공증이 없습니다. 다운로드한 앱 실행을 macOS가 차단하면 공식 배포처와 파일을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 **그래도 열기**를 선택하세요. 운영체제 전체 보안 설정을 끄지 마세요. 최초 인증이나 런처 교체 후 키체인 접근 허용을 요청할 수 있습니다. 이를 거절하면 인증 정보를 저장하지 못합니다.

지원 빌드 준비 중으로 표시되면 해당 운영체제용 게임이 아직 게시되지 않은 상태입니다. 맥 게임은 Windows와 같은 BUILD 번호·통신 규약인지 확인한 뒤 함께 테스트하세요. 실제 친구의 맥에서 게임 실행·화면·Windows와의 네트워크 플레이는 별도의 플레이테스트 확인 대상입니다.

게임 관리 메뉴에서 버전 정보, 설치 폴더, 로그, 파일 복구, 이전 버전 복원과 삭제를 사용할 수 있습니다. 설치 파일을 삭제해도 별도 저장 데이터와 테스트 로그는 유지됩니다. 게임 실행 중 설치·삭제·복원은 차단합니다.

인증된 이메일과 최초·최근 인증/접속 시각은 TeamHJD 운영 서버에 기록됩니다. 인증 토큰은 이 맥의 키체인에 보관한 키로 암호화합니다. 게임 로그를 자동 업로드하지 않습니다.

설정·게임 기본 경로는 `~/Library/Application Support/TeamHJD/Launcher/`, 런처 관리 버전은 같은 TeamHJD 폴더의 `LauncherRuntime-macos-arm64/` 또는 `LauncherRuntime-macos-x64/`입니다. 응용 프로그램 폴더의 원본 앱을 자동 업데이트 과정에서 수정하지 않습니다.

접속이 안 되면 인터넷과 인증 만료 여부를 확인하세요. 운영 PC는 Windows 사용자 로그인 상태에서 절전 없이 켜져 있고 인터넷에 연결되어 있어야 배포 서버가 동작합니다. 런처의 배포 서버와 실제 게임의 멀티플레이 호스트는 별개입니다.

Apple의 [개발자를 확인할 수 없는 Mac 앱 열기 안내](https://support.apple.com/ko-kr/guide/mac-help/mh40616/mac)를 참고할 수 있습니다.

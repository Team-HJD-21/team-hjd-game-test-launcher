# Mac에서 플레이테스트 시작하기

[다운로드 페이지](https://testlauncher.teamhjd.com/)는 TeamHJD 홈페이지 푸터 **관련 사이트 → Game Test Launcher**에서 열 수 있습니다. macOS15 이상에서 Apple Silicon(M1 이상)은 **ARM DMG**, Intel은 **Intel DMG**를 받으세요.

1. DMG를 열고 **TeamHJDLauncher.app**을 응용 프로그램 폴더로 옮깁니다. DMG 안에서 계속 실행하지 말고 복사한 앱을 실행합니다. Dock에도 이 앱을 고정합니다.
2. 런처 업데이트 확인 후 온라인 참여 안내의 개인정보 수집·이용과 Cloudflare 국외 처리 선택을 각각 확인합니다. 만14세 미만은 법정대리인 동의 절차를 담당자에게 문의하세요.
3. **브라우저에서 인증**으로 이메일과 수신 코드를 입력한 뒤 런처로 돌아옵니다.
4. **설치 → 플레이**로 Mac 게임을 시작합니다. 새 게임 버전은 **업데이트**를 눌러 직접 적용합니다. **현재 버전 플레이**로 기존 게임을 유지할 수 있습니다.

기존 ZIP 사용자는 런처를 종료하고 새 DMG의 앱으로 교체하세요. 같은 사용자 계정의 게임과 설정을 이어서 사용합니다. Windows 게임 파일을 Mac에 복사해 설치하지 않습니다.

공식 이메일 인증 도구의 실제 최소 요구 버전에 따라 macOS15 이상을 지원합니다. 앱 번들의 최소 버전도15.0이며 더 낮은 버전의 동작을 지원한다고 안내하지 않습니다.

## 첫 실행과 업데이트

현재 Apple Developer ID 서명·공증이 없습니다. 공식 출처를 확인한 앱만 시스템 설정 → 개인정보 보호 및 보안의 해당 앱 **그래도 열기**로 승인하세요. 손상·악성코드 경고는 실행을 중단하고 문의하세요. Gatekeeper 전체 해제나 quarantine 일괄 삭제를 사용하지 않습니다. 키체인 접근 승인이 필요할 수 있으며 거부하면 인증 정보 저장에 영향을 줄 수 있습니다.

인터넷 연결·최신 런처 확인·이메일 인증을 마쳐야 게임을 실행할 수 있습니다. 오프라인 우회는 제공하지 않습니다. 새 런처는 업데이트 시작을 눌러 승인한 뒤 다운로드·검증·적용하며 자동으로 다시 실행됩니다. 연결 오류는 자동으로 재확인하고 업데이트 승인은 이메일 인증보다 먼저 표시합니다.

자동 업데이트는 응용 프로그램의 안정된 앱도 관리합니다. 폴더에 쓰기 권한이 없거나 읽기 전용 DMG에서 실행하면 교체에 실패할 수 있습니다. 앱을 종료하고 최신 DMG로 복구하거나, 현재 사용자에게 쓰기 가능한 `~/Applications`에 앱을 설치하세요. 보안·권한 검증을 끄지 않습니다.

## 관리·제거·개인정보

게임 관리에서 버전 정보, 설치 폴더, 로그, 파일 복구, 이전 버전 복원과 게임 삭제를 사용할 수 있습니다. 게임 실행 중 변경은 차단하며 삭제 시 Unity 저장 데이터·로그는 보존합니다.

런처 제거는 응용 프로그램의 **TeamHJDLauncher.app을 휴지통으로 이동**합니다. 게임·설정·로그인 정보와 서버 기록은 보존합니다. 파일이 손상되면 최신 DMG의 앱으로 교체한 뒤 실행하세요. 로그인 정보만 지우려면 런처 **파일 → 이 PC의 로그인 정보 삭제**를 사용합니다. 서버 기록 삭제·동의 철회·처리정지는 **support@teamhjd.com**으로 요청할 수 있습니다.

설정·게임 기본 경로는 `~/Library/Application Support/TeamHJD/Launcher/`이며, 런처 관리 버전은 같은 TeamHJD 폴더의 `LauncherRuntime-macos-arm64/` 또는 `LauncherRuntime-macos-x64/`입니다. 별도로 선택한 게임 경로도 유지합니다.

인증 이메일·시각·세션 횟수와 동의 기록은 비공개 운영 서버에 보관하며 최근 접속 후180일 기준으로 정리합니다. 연결 정보는 키체인으로 보호하고 게임 로그는 자동 업로드하지 않습니다. [전체 이용조건·개인정보 안내](https://testlauncher.teamhjd.com/privacy.html)를 확인하세요.

실제 친구의 Mac 게임 플레이·Windows와 크로스플레이는 별도 플레이테스트입니다. 배포 서버가 켜져 있는 것만으로 멀티플레이 게임 방이 자동 생성되지는 않습니다.
